# Password Tool

![C#](https://img.shields.io/badge/C%23-239120?logo=csharp&logoColor=white)
![.NET 10](https://img.shields.io/badge/.NET-10-512BD4?logo=dotnet&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green)

Console tool that rates password strength and generates random passwords. Passwords are evaluated locally and never stored.

برنامه کنسول برای دو کار: سنجیدن قدرت یک رمز، و ساختن رمز تصادفی.

رمز فقط همان لحظه روی همین دستگاه بررسی می‌شود و جایی ذخیره نمی‌شود. امتیاز از طول رمز و بودن حرف کوچک، حرف بزرگ، عدد و علامت ساخته می‌شود.

.NET 10.

## اجرا

```bash
dotnet run --project PasswordTool/PasswordTool.csproj
```
